# Fatm Elsayed Portfolio

This is a static portfolio site. Start at `index.html`; no build step is required. Serve the project over HTTP to preview video playback.

## Project layout

- `index.html` — page structure.
- `assets/css/styles.css` — page layout, themes, and section transitions.
- `assets/js/main.js` — navigation and scroll interactions.
- `assets/images/` — shared page imagery.
- `assets/portfolio/` — artwork grouped by project.
- `assets/videos/` — project videos and preview images.
- `assets/certificates/` — certificates shown after the project galleries.

## Updating the portfolio

Place new files in the matching folder and update the corresponding section in `index.html`. Use descriptive, lowercase file names when adding assets; URL-encode spaces and non-ASCII characters in HTML paths.
